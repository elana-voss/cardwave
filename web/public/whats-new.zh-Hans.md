# 0.1.3

小修复。

- Cardwave 已打开时再次启动，会把它的窗口带到最前面；因其他程序占用端口而无法启动时，会告诉你原因。
- 更易阅读：深色主题中蓝色按钮上的文字和空白处的提示，浅色主题中你的姓名缩写。
- 聊天：已发送消息中的骰子、随机选择和变量，在之后的每条回复中都保持不变。
- 资料库和角色页面上的日期和时间跟随你的语言。
- 听写连一个短词也能听到，没有标点的长句也会完整朗读。

# 0.1.2

第三轮测试带来的更多修复。

- 记忆：编辑较早的消息后，你修改或删除的内容保持不变；给角色或人设改名后，他们记得的内容也会保留。
- 聊天：发送消息时输入的文字会留在输入框中，切换标签页时听写会保留最后的话，问候语中的日期跟随你的语言。
- 当这台电脑上的模型未通过测试、下载的服务器出错、检查更新无法完成时，提示更加清楚。
- 无论窗口如何变窄，标签页都能放下。

# 0.1.1

第二轮测试中发现的问题的修复。

- 备份：恢复会等待仍在进行的工作，备份文件以你自己的日期命名。
- 首次运行：在设置中添加的服务商会继续选择模型，被拒绝的密钥会说明已被拒绝，用改正后的密钥重新设置时仍只保留一个服务商。
- 聊天：对模型来说过长的角色会告知你，而不是被省略；附加的图片只缩小一次，离开聊天后仍保持附加。
- 密码界面和其他设备的登录使用你的语言，设置也能适应手机的宽度。
- 对文字、标签页、图片和导入的许多小修复。

# 0.1.0

从头重新打造的 Cardwave：与你资料库中的角色聊天，模型可在这台电脑上运行，也可用服务商的。

- 你的资料库：导入 SillyTavern 和 CCV4 角色卡，或自己创建，并按文字或含义查找。
- 与一个或多个角色聊天，他们轮流回复或自行回复，支持版本、其他走向、人设和世界书。
- 任意服务商：粘贴 API 密钥，Cardwave 就知道它属于哪家；也可选择这台电脑上的 GGUF 模型。
- 记忆：角色记得你们聊天中发生的事。
- 语音：在这台电脑上用每个角色自己的声音朗读回复，也支持语音输入。
- 工具（只用你打开的）：网页搜索、一个文件夹里的文件、图片。
- 十二种语言、浅色和深色主题、密码和备份。
