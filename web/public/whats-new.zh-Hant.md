# 0.3.2

夥伴的臉活了起來，還會回應你的觸碰。

- 帶臉部形態的 3D 形象會眨眼、看著你，並在臉上表現它的情緒和聲音，支援 VRM、GLB 和 FBX。
- 即使沒有語音，回覆傳來時夥伴的嘴唇也會動。
- 點擊夥伴的頭、手或身體的其他部位：它會嚇一跳，角色會在對話泡泡裡回應。雙擊仍會開啟聊天。
- 無論什麼尺寸，夥伴都會把腳放在視窗底邊上站立、躺下和行走，走路時不再打滑。
- 你加入的 VRM 形象會顯示它的作者。
- 聊天側邊欄在「這則回覆中用到」下列出回覆用到的每個工具。
- 設定 › 進階 › AI 的工具 中新增：「新角色的名字」，讓 AI 從一個符合文化、時代和題材的大清單中為每個新角色取名。

# 0.3.1

針對 Linux 的一個小修正。

- 在 Linux 上無法開始朗讀時，Cardwave 現在會請你重新安裝它，而不再要求安裝 Linux 上並不存在的 Microsoft 元件。

# 0.3.0

Linux 版 Cardwave。

- Cardwave 可在 Linux 上執行：發布頁面提供 AppImage（可在大多數 Linux 電腦上執行）和 .deb（可在 Ubuntu 和 Debian 上安裝）。
- 在 Linux 上同樣會用你的顯示卡辨識人臉，麥克風可在 Cardwave 的視窗中使用，AI 的程式設計工具可以執行指令。
- 小修正：頁面頂端的按鈕能放進窄視窗，載入你的帳戶時帳戶選單保持開啟。

# 0.2.0

在手機上使用 Cardwave，以及許多修正。

- 隨時隨地開啟 Cardwave：有了 Tailscale，「帳號 › 共享」會顯示在手機或另一台電腦上開啟它的網址，而且每個畫面都適合手機。
- 記憶屬於一個角色和你的人設：切換聊天的人設會開始新的記憶，切換回來又能找到原來的記憶。
- 夥伴動得更多了：依心情挑選的大量新動作，以及四種新情緒：害怕、調皮、害羞和疲倦。
- 在支援的電腦上，3D 形象以 WebGPU 繪製。
- 首次啟動時就能還原備份，還原的備份保留它的密碼。
- 設定更整齊：AI 的工具移到了「進階」，分頁可以在「設定 › 外觀」中關閉。
- 指向角色的文字時會顯示「點擊編輯」，工作列圖示也填滿了它的方格。
- 在全面檢查整個應用程式時發現的許多修正。

# 0.1.3

小修正。

- Cardwave 已開啟時再次啟動，會把它的視窗帶到最前面；因其他程式占用連接埠而無法啟動時，會告訴你原因。
- 更易閱讀：深色主題中藍色按鈕上的文字和空白處的提示，淺色主題中你的姓名縮寫。
- 聊天：已傳送訊息中的骰子、隨機選擇和變數，在之後的每則回覆中都保持不變。
- 資料庫和角色頁面上的日期和時間跟隨你的語言。
- 聽寫連一個短詞也能聽到，沒有標點的長句也會完整朗讀。

# 0.1.2

第三輪測試帶來的更多修正。

- 記憶：編輯較早的訊息後，你修改或刪除的內容保持不變；替角色或人設改名後，他們記得的內容也會保留。
- 聊天：傳送訊息時輸入的文字會留在輸入框中，切換分頁時聽寫會保留最後的話，問候語中的日期跟隨你的語言。
- 當這台電腦上的模型未通過測試、下載的伺服器出錯、檢查更新無法完成時，提示更加清楚。
- 無論視窗如何變窄，分頁都能放得下。

# 0.1.1

第二輪測試中發現的問題的修正。

- 備份：還原會等待仍在進行的工作，備份檔以你自己的日期命名。
- 首次執行：在設定中新增的供應商會繼續選擇模型，被拒絕的金鑰會說明已被拒絕，用改正後的金鑰重新設定時仍只保留一個供應商。
- 聊天：對模型來說過長的角色會告知你，而不是被省略；附加的圖片只縮小一次，離開聊天後仍保持附加。
- 密碼畫面和其他裝置的登入使用你的語言，設定也能符合手機的寬度。
- 對文字、分頁、圖片和匯入的許多小修正。

# 0.1.0

從頭重新打造的 Cardwave：與你資料庫中的角色聊天，模型可在這台電腦上執行，也可用供應商的。

- 你的資料庫：匯入 SillyTavern 和 CCV4 角色卡，或自己建立，並依文字或意思搜尋。
- 與一個或多個角色聊天，他們輪流回覆或自行回覆，支援版本、其他走向、使用者角色和世界書。
- 任何供應商：貼上 API 金鑰，Cardwave 就知道它屬於哪家；也可選擇這台電腦上的 GGUF 模型。
- 記憶：角色記得你們聊天中發生的事。
- 語音：在這台電腦上用每個角色自己的聲音朗讀回覆，也支援聽寫。
- 工具（只用你開啟的）：網頁搜尋、一個資料夾裡的檔案、圖片。
- 十二種語言、淺色和深色主題、密碼和備份。
