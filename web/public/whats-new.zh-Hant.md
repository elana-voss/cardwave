# 0.1.2

第三輪測試帶來的更多修正。

- 記憶：編輯較早的訊息後，你修改或刪除的內容保持不變；替角色或人設改名後，他們記得的內容也會保留。
- 聊天：傳送訊息時輸入的文字會留在輸入框中，切換分頁時聽寫會保留最後的話，問候語中的日期跟隨你的語言。
- 當這台電腦上的模型未通過測試、下載的伺服器出錯、檢查更新無法完成時，提示更加清楚。
- 無論視窗如何變窄，分頁都能放得下。

# 0.1.1

第二輪測試中發現的問題的修正。

- 備份：還原會等待仍在進行的工作，備份檔以你自己的日期命名。
- 首次執行：在設定中新增的供應商會繼續選擇模型，被拒絕的金鑰會說明已被拒絕，用改正後的金鑰重新設定時仍只保留一個供應商。
- 聊天：對模型來說過長的角色會告知你，而不是被省略；附加的圖片只縮小一次，離開聊天後仍保持附加。
- 密碼畫面和其他裝置的登入使用你的語言，設定也能符合手機的寬度。
- 對文字、分頁、圖片和匯入的許多小修正。

# 0.1.0

從頭重新打造的 Cardwave：與你資料庫中的角色聊天，模型可在這台電腦上執行，也可用供應商的。

- 你的資料庫：匯入 SillyTavern 和 CCV4 角色卡，或自己建立，並依文字或意思搜尋。
- 與一個或多個角色聊天，他們輪流回覆或自行回覆，支援版本、其他走向、使用者角色和世界書。
- 任何供應商：貼上 API 金鑰，Cardwave 就知道它屬於哪家；也可選擇這台電腦上的 GGUF 模型。
- 記憶：角色記得你們聊天中發生的事。
- 語音：在這台電腦上用每個角色自己的聲音朗讀回覆，也支援聽寫。
- 工具（只用你開啟的）：網頁搜尋、一個資料夾裡的檔案、圖片。
- 十二種語言、淺色和深色主題、密碼和備份。
