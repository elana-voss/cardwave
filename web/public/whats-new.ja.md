# 0.1.2

3回目のテストからのさらなる修正。

- メモリー：以前のメッセージを編集しても、あなたが変更・削除した内容はそのまま残ります。キャラクターやペルソナの名前を変えても、覚えていることは失われません。
- チャット：送信中に入力した言葉は入力欄に残り、タブを切り替えても音声入力の最後の言葉は残り、あいさつの日付はあなたの言語で表示されます。
- このコンピューターのモデルがテストに失敗したとき、ダウンロード先のサーバーが失敗したとき、アップデートの確認が終わらなかったときのメッセージがわかりやすくなりました。
- ウィンドウがどのように狭くなっても、タブが収まります。

# 0.1.1

2回目のテストで見つかった問題の修正。

- バックアップ：復元は実行中の作業を待ち、バックアップファイルはあなた自身の日付で名付けられます。
- 初回起動：設定で追加したプロバイダーはモデルの選択へ進み、拒否されたキーは拒否されたと伝え、修正したキーで再設定してもプロバイダーは1つのままです。
- チャット：モデルには長すぎるキャラクターは省かれずに知らされます。添付した画像は一度だけ縮小され、チャットを離れても添付されたままです。
- パスワード画面と他のデバイスのサインインがあなたの言語に。設定はスマートフォンの幅に収まります。
- テキスト、タブ、画像、インポートの細かな修正を多数。

# 0.1.0

一から作り直したCardwave。ライブラリのキャラクターとチャットできます。モデルはこのコンピューター上でも、プロバイダーでも使えます。

- ライブラリ：SillyTavernとCCV4のカードをインポートするか自分で作り、言葉や意味から探せます。
- 1人または複数のキャラクターとのチャット。順番に、または自分から返信し、バージョン、別の展開、ペルソナ、ロアブックも使えます。
- どのプロバイダーでも：APIキーを貼り付ければCardwaveがどこのキーか判断します。このコンピューター上のGGUFモデルも選べます。
- 記憶：キャラクターはチャットで起きたことを覚えています。
- 音声：返信をこのコンピューター上で各キャラクター自身の声で読み上げます。音声入力にも対応。
- ツール（オンにしたものだけ）：ウェブ検索、1つのフォルダーのファイル、画像。
- 12の言語、ライトとダークのテーマ、パスワードとバックアップ。
