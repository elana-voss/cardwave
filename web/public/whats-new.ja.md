# 0.3.3

Cardwave は各 AI が一度に読める量を知るようになり、AI が考える量を選んだり、チャットに色を付けたりできます。

- 設定 › プロバイダーで、考える量を増減できるモデルに、オフ、軽め、標準、じっくりが表示されるようになりました。選んだ内容はモデルごとに保存されます。プロバイダーがあるモデルの思考をオフにできない場合は、Cardwave がそう伝えます。
- 表示メニューに「チャットのメッセージの色」（オフ、ライト、ダーク）が加わりました。引用符で囲んだセリフ、斜体、太字、リンク、コードがそれぞれの色で表示されます。キャラクターのチャットとコンパニオンで使えます。
- 長さの上限で途切れた返信は、最後の完全な一文で終わるようになりました。AI 自身の上限で止まった返信はそのまま残り、その下にそれを示す灰色の行が付きます。「この返信の続きを書く」は最後の単語から続けます。
- ヘルパーモデルがチャットの記憶を保てないときは、その理由がチャットに表示されます。
- OpenRouter または NanoGPT 経由で Claude モデルと行う長いチャットは、プロンプトキャッシュにより、費用が下がり、応答も早くなります。
- コーディングタスクでは、各ステップの行があなたの言語で表示され、Web ページもより正確に読み取られます。
- 返信はそれぞれのモデルが読める量に収まります。Cardwave はその量を内蔵のモデル一覧から取るか、このコンピューター（LM Studio、Ollama、KoboldCpp）やローカルネットワーク上の AI 自身に尋ねます。以前はどのモデルにも 128,000 トークンを当てていました。
- より多く読めるモデルとの長いチャットは、履歴をより多く残すようになりました。
- AI の量がわからないときは返信でお知らせします。設定 › 詳細設定 でコンテキストサイズとして一度設定してください。それまでは何も送信しません。
- 設定 › 詳細設定 のコンテキストサイズは、どのモデルに送る量にも上限をかけるようになりました。

# 0.3.2

コンパニオンの顔が生き生きと動き、触れると応えます。

- 顔のシェイプを持つ 3D フィギュアがまばたきし、あなたを見て、気持ちと声を顔に表します（VRM、GLB、FBX）。
- 音声がなくても、返信が届く間はコンパニオンの唇が動きます。
- コンパニオンの頭や手、体の他の部分をクリックすると、驚いて、キャラクターが吹き出しで答えます。ダブルクリックでは今まで通りチャットが開きます。
- どのサイズでも、コンパニオンはウィンドウの下端に足をつけて立ち、横になり、歩きます。歩くときに滑らなくなりました。
- 追加した VRM フィギュアは作者の名前を表示します。
- チャットのサイドパネルの「この返信で使用」に、返信が使ったツールがすべて並びます。
- 設定 › 詳細設定 › AIのツール に新しく「新しい登場人物の名前」：AI が新しい登場人物の名前を、文化・時代・ジャンルに合う大きなリストから選びます。

# 0.3.0

Linux で使える Cardwave。

- Cardwave が Linux で動きます：リリースページに、ほとんどの Linux コンピューターで動く AppImage と、Ubuntu と Debian にインストールできる .deb があります。
- Linux でも、顔はグラフィックカードで検出され、マイクは Cardwave のウィンドウで使え、AI のコーディングツールはコマンドを実行します。
- 小さな修正：ページ上部のボタンが狭いウィンドウに収まり、アカウントの読み込み中もアカウントメニューが開いたままになります。

# 0.2.0

スマートフォンで使える Cardwave と、多くの修正。

- どこからでも Cardwave を開けます：Tailscale があれば、アカウント › 共有 に、スマートフォンや別のコンピューターで開くためのアドレスが表示されます。どの画面もスマートフォンに収まります。
- 記憶はキャラクターとあなたのペルソナに結びつきます：チャットのペルソナを切り替えると新しい記憶が始まり、元に戻すと以前の記憶が戻ります。
- コンパニオンがよく動くようになりました：気分に合わせて選ばれる多くの動きと、怖がる、ふざける、照れる、疲れる の四つの感情が加わりました。
- お使いのコンピューターが対応していれば、3D フィギュアは WebGPU で描かれます。
- 最初の起動時にすぐバックアップを復元でき、復元したバックアップはパスワードをそのまま保ちます。
- 設定を整理しました：AI のツールは「詳細設定」に移り、タブは 設定 › 外観 でオフにできます。
- キャラクターのテキストにポインターを合わせると「クリックして編集」と表示され、タスクバーのアイコンが枠いっぱいに描かれます。
- アプリ全体の点検で見つかった多くの修正。

# 0.1.3

細かな修正。

- Cardwaveを開いたまま再び起動すると、そのウィンドウが前面に出ます。ほかのプログラムがポートを使っていて起動できないときは、そう表示します。
- 読みやすく：ダークテーマの青いボタンの文字と空欄の案内、ライトテーマのあなたのイニシャル。
- チャット：送信したメッセージのダイス、ランダムな選択、変数は、その後のどの返信でも同じままです。
- ライブラリーとキャラクターのページの日付と時刻があなたの言語で表示されます。
- 音声入力は短い一語でも聞き取り、句読点のない長い文も最後まで読み上げます。

# 0.1.2

3回目のテストからのさらなる修正。

- メモリー：以前のメッセージを編集しても、あなたが変更・削除した内容はそのまま残ります。キャラクターやペルソナの名前を変えても、覚えていることは失われません。
- チャット：送信中に入力した言葉は入力欄に残り、タブを切り替えても音声入力の最後の言葉は残り、あいさつの日付はあなたの言語で表示されます。
- このコンピューターのモデルがテストに失敗したとき、ダウンロード先のサーバーが失敗したとき、アップデートの確認が終わらなかったときのメッセージがわかりやすくなりました。
- ウィンドウがどのように狭くなっても、タブが収まります。

# 0.1.1

2回目のテストで見つかった問題の修正。

- バックアップ：復元は実行中の作業を待ち、バックアップファイルはあなた自身の日付で名付けられます。
- 初回起動：設定で追加したプロバイダーはモデルの選択へ進み、拒否されたキーは拒否されたと伝え、修正したキーで再設定してもプロバイダーは1つのままです。
- チャット：モデルには長すぎるキャラクターは省かれずに知らされます。添付した画像は一度だけ縮小され、チャットを離れても添付されたままです。
- パスワード画面と他のデバイスのサインインがあなたの言語に。設定はスマートフォンの幅に収まります。
- テキスト、タブ、画像、インポートの細かな修正を多数。

# 0.1.0

一から作り直したCardwave。ライブラリのキャラクターとチャットできます。モデルはこのコンピューター上でも、プロバイダーでも使えます。

- ライブラリ：SillyTavernとCCV4のカードをインポートするか自分で作り、言葉や意味から探せます。
- 1人または複数のキャラクターとのチャット。順番に、または自分から返信し、バージョン、別の展開、ペルソナ、ロアブックも使えます。
- どのプロバイダーでも：APIキーを貼り付ければCardwaveがどこのキーか判断します。このコンピューター上のGGUFモデルも選べます。
- 記憶：キャラクターはチャットで起きたことを覚えています。
- 音声：返信をこのコンピューター上で各キャラクター自身の声で読み上げます。音声入力にも対応。
- ツール（オンにしたものだけ）：ウェブ検索、1つのフォルダーのファイル、画像。
- 12の言語、ライトとダークのテーマ、パスワードとバックアップ。
