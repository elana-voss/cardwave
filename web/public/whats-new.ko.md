# 0.1.3

작은 수정.

- Cardwave가 열려 있을 때 다시 실행하면 창이 앞으로 나오고, 다른 프로그램이 포트를 쓰고 있어 시작할 수 없으면 그렇다고 알려 줍니다.
- 더 읽기 쉽게: 어두운 테마의 파란 버튼 글자와 빈 칸 안내, 밝은 테마의 이니셜.
- 채팅: 보낸 메시지의 주사위, 무작위 선택, 변수가 이후의 모든 답장에서 그대로 유지됩니다.
- 라이브러리와 캐릭터 페이지의 날짜와 시간이 사용자의 언어를 따릅니다.
- 받아쓰기가 짧은 한 단어도 알아듣고, 문장 부호 없는 긴 문장도 끝까지 읽어 줍니다.

# 0.1.2

세 번째 테스트에서 찾은 문제를 더 고쳤습니다.

- 기억: 이전 메시지를 수정해도 사용자가 바꾸거나 지운 내용은 그대로 남고, 캐릭터나 페르소나의 이름을 바꿔도 기억하는 내용이 유지됩니다.
- 채팅: 메시지를 보내는 동안 입력한 글은 입력란에 남고, 탭을 바꿔도 받아쓰기의 마지막 말이 남으며, 인사말의 날짜가 사용자의 언어를 따릅니다.
- 이 컴퓨터의 모델이 테스트를 통과하지 못할 때, 다운로드 서버가 실패할 때, 업데이트 확인을 마치지 못할 때의 안내가 더 분명해졌습니다.
- 창이 어떻게 좁아지든 탭이 창에 맞게 들어갑니다.

# 0.1.1

두 번째 테스트에서 찾은 문제를 고쳤습니다.

- 백업: 복원은 아직 진행 중인 작업을 기다리고, 백업 파일은 사용자의 날짜로 이름이 붙습니다.
- 첫 실행: 설정에서 추가한 제공자는 모델 선택으로 이어지고, 거부된 키는 거부되었다고 알려 주며, 고친 키로 다시 설정해도 제공자는 하나로 유지됩니다.
- 채팅: 모델에 너무 긴 캐릭터는 빠지지 않고 알려 드립니다. 첨부한 사진은 한 번만 줄이며, 채팅을 떠나도 첨부된 채로 남습니다.
- 비밀번호 화면과 다른 기기의 로그인이 사용자의 언어로 나오고, 설정이 휴대폰 너비에 맞습니다.
- 텍스트, 탭, 사진, 가져오기의 작은 수정 여러 가지.

# 0.1.0

처음부터 새로 만든 Cardwave. 라이브러리의 캐릭터와 채팅하세요. 모델은 이 컴퓨터에서도, 제공자에서도 쓸 수 있어요.

- 라이브러리: SillyTavern과 CCV4 카드를 가져오거나 직접 만들고, 단어나 의미로 찾을 수 있어요.
- 한 캐릭터나 여러 캐릭터와의 채팅. 차례로 또는 스스로 답하고, 버전, 다른 전개, 페르소나, 로어북도 있어요.
- 어떤 제공자든: API 키를 붙여 넣으면 Cardwave가 어디 키인지 알아내요. 이 컴퓨터의 GGUF 모델을 골라도 돼요.
- 기억: 캐릭터가 채팅에서 있었던 일을 기억해요.
- 음성: 답장을 이 컴퓨터에서 캐릭터마다 자기 목소리로 읽어 주고, 음성 입력도 돼요.
- 도구(켠 것만): 웹 검색, 폴더 하나의 파일, 그림.
- 12개 언어, 밝은 테마와 어두운 테마, 비밀번호와 백업.
